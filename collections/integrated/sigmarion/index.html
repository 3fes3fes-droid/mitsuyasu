NTT DoCoMo Handheld PC / 2000–2003

sigmarionシグマリオンの歴史

スマートフォン以前、「携帯回線につないで外で文章を書き、メールし、Webを見る」ための小型Windows CEマシン。初代からIIIまで、わずか3年で画面・CPU・通信環境が大きく進化した。

3分で分かる年表

sigmarionは、ドコモの通信サービスとWindows CEを組み合わせた「通信するハンドヘルドPC」として展開された。

2000.09.20

初代 sigmarion 発売

Windows CE Handheld PC Pro 3.0を搭載。6.2型640×240液晶とフルキーボードを約485gの筐体に収め、携帯電話・PHSと接続してモバイル通信できた。ゼロハリバートン風の外装も大きな個性だった。

発表時価格 59,800円（ドコモ支店・営業所）
2001.09.07

sigmarion II 発売

外観の基本路線を保ちながら、CPUをVR4131 200MHzへ高速化。OSはWindows for Handheld PC 2000に更新され、HPA液晶、16MB Flash ROM、FOMA接続インターフェイスなどを追加した。

初代の「完成形」に近い正常進化モデル
2003.05.28

sigmarion III 発売

筐体を全面刷新。5型800×480のワイドVGA、PXA255 400MHz、64MB RAM、Windows CE .NET 4.1を採用。CFとSDIOを同時搭載し、Picsel BrowserでOffice文書やPDFの閲覧にも対応した。

薄さ21mm・約455g。シリーズ最大の性能ジャンプ
2004

III向けサービス対応が継続

ドコモは@FreeD向けデータ圧縮サービス「ネットハイウェイ」をsigmarion IIIへ対応させるなど、発売後も通信端末としての運用を拡張した。

なぜ当時、特別だったのか

2000年前後は、ノートPC・PDA・携帯電話が別々の役割を持っていた時代。sigmarionはその隙間をかなり明確に埋めた。

01

物理キーボード

スタイラス中心のPDAより長文入力に向き、メール、日記、原稿、掲示板への書き込みなど「外で文字を書く」用途と相性が良かった。

02

携帯回線と一体運用

本体単独でセルラー通信する機械ではなく、PHSカードや携帯電話/FOMA端末を接続する設計。ドコモの通信サービスを持ち歩く端末だった。

03

即起動する小型PC

Windows CE機はPC用Windowsより軽量で、サスペンド復帰が速い。ノートPCを開くほどではない場面で、すぐ文章や予定表を扱えた。

IIIで到達したもの

sigmarion IIIは、5インチ800×480、400MHz CPU、SDIO・CF・USBホスト、FOMA/PHS接続という構成で、「小型なのにPC的に使える」方向を強く押し進めた。ドコモ自身も開発時に、IIの軽快さとノートPCの用途を合わせるコンセプトを説明している。

その後、携帯電話の高機能化、無線LANの普及、スマートフォンや小型ノートPCの進化によって、キーボード付きWindows CEハンドヘルドというカテゴリ自体が縮小した。sigmarionは市販シリーズとしてIIIで一区切りとなった。
