# YouTube「100の質問」動画の調査データ

初回調査: 2026-11-22。公開中の光康サイトに影響しない独立ブランチ。

- `video-seeds.tsv`: YouTube動画IDを28件記録。ジャンル横断・重複なし。
- 大原優乃: 概要欄の100問と再生時間の索引を100件作成済み。
- kemio / 福原遥: 公開文字起こし・報道で確かめた回答の要約を44件作成済み。
- 完全な質問・回答JSON、CSV、テスト済み収集用Pythonスクリプトは初回調査のチャット添付ZIPに収録。
- 次に必要なのは、ネットワーク接続できるWindows N100等で `yt-dlp` を使い字幕・説明欄の実取得を検証すること。

**状況:** ここまでの28本は候補発見・同定済み。100問/100答を全件確認した28パッケージではない。

**既知の障害:** 実行コンテナからYouTubeへの直接通信はDNS名前解決失敗。YouTube字幕の大量取得は未試行。公式の captions.download APIでは他者の動画を自由に取得できない。

## 運用方針
1. タイトルと動画IDで候補を発見・重複除去
2. 概要欄から質問番号・本文の短いラベル・時刻を抽出
3. 公開字幕が取得できれば質問ごとの回答を抽出・要約
4. 人手/AIで確認した回答だけ表示用データに反映
5. 部分取得、欠番、前後編などは明示的に区別
