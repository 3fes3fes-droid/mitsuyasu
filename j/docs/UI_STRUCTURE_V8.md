# v8 閲覧構造

## 設計の軸

縦にカードを積み続ける旧構造を廃止し、データベース閲覧に向いた「一覧＋詳細」の2ペインへ変更しました。

参照した公開設計ガイド：

- Material Design canonical layouts  
  https://m3.material.io/foundations/layout/canonical-examples/overview
- Notion database layouts  
  https://www.notion.com/help/layouts
- Linear Peek preview  
  https://linear.app/docs/peek
- Carbon Design System data table  
  https://v10.carbondesignsystem.com/components/data-table/usage/

## PC表示

- 画面上部：高さ54pxの共通ナビゲーション
- 左：検索・分類・一覧。左ペイン内だけをスクロール
- 右：選択中レコードの見出し、要約、タブ、本文
- 人物・技・用語：`概要 / 関連 / 出典・確認`
- 各話：`あらすじ / 登場・関連 / 名言・キーワード / 出典・確認`
- コミックス：`収録話 / 巻末補遺 / 出典・巻情報`
- 補遺：`概要 / 人物 / 出典・確認`

詳細ページ全体はPCで画面高に収め、必要な場合だけレコード本文部分をスクロールします。公式画像未収集の各話では空の大きな画像枠を出しません。登録済み画像は前版と同じ自然比率、最大320×408pxで表示します。

## 情報密度

- 一覧行は原則43px
- タイトルと主分類を一行内で表示
- 収録話はカードではなく短い表
- 関連話は複数列の短いリンク
- 出典・確認状態は常時表示せず専用タブへ分離
- 出典台帳はページ全体ではなく表領域だけをスクロール

### 名言・キーワードタブ

- 最上段：二つ以上の漫画記事系統で同一文言を確認した短い作中語句・発言をPCで3列表示
- 最上段は6件まで展開し、7件目以降を閉じた `details` 内へ格納
- 次段：代表的な名言・話題句、セリフ・判断・言動要旨、キーワードをPCで3列表示
- 中段：詳細出来事をPCで最大3列の短いタイムライン表示
- 下段：技・術式と用語を2列表示
- 件数バーで名言・語句、言動、出来事、キーワードの登録量を即確認
- 1180px以下は2列、820px以下は1列へ段階的に変形

長い台詞本文を並べず、短い逐語引用、二次記事で照合した短文、独自の名言要旨を区別します。照合短文の話者は原作ページ直接監査まで表示しません。全275話に3件以上の言動要旨と2件以上のキーワードがあるため、短文照合がない回でも判断・心情・局面を追えます。

照合短文がある話では、`出典・確認` タブにその話の照合記事URLを重複排除して表示します。短文欄へURLを繰り返さないため、閲覧密度と検証導線を両立します。

## 操作

- 一覧の上下キー・Home・Endで選択レコードを移動
- タブの左右キー・Home・Endで表示内容を切替
- `?id=` 付き直接リンクを維持
- 人物・技・用語の通常読込時ランダム表示を維持

## 文字サイズ一時調整

全実ページの右下に `文字サイズ` ボタンを表示します。次の10項目を個別調整できます。

- 全体の基本文字
- 上部メニュー
- 左側の一覧
- 詳細タイトル
- 見出し下あらすじ
- 詳細タブ
- 本文・出来事
- 項目・関連リンク
- 項目見出し
- 収録話・出典表

値はブラウザのローカル保存領域へ残ります。`採用値をコピー` でCSS変数を取得し、最終値決定後に固定して調整欄を撤去できます。

## 狭い画面

820px以下では固定高を解除し、一覧と詳細を縦に並べます。PC向けの情報密度を優先しつつ、小さい画面で内容が消える処理は使用しません。
