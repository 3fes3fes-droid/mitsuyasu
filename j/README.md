# 呪術廻戦 原作漫画データベース

漫画0巻全4話、本編第1話～第271話、30巻描き下ろしエピローグを対象とした静的HTMLデータベースです。PCでの閲覧を主に設計していますが、狭い画面でもサイト全体を遮断しません。アニメ、劇場版、ゲーム、小説、舞台は対象外です。

人物・技／術式・用語ページは、通常のページ表示ごとに一覧順と最初の表示項目をランダム化します。別ページからのリンクや `?id=...` 付きURLは指定項目を維持するため、直接リンクは壊れません。

各話サムネイルは、URLを推測して埋めていません。確認できていない274件は画面で「公式サムネイルURL未収集」と表示します。収集用スクリプトは同梱しています。

各話には `名言・キーワード` タブがあります。短い逐語引用、漫画記事を横断照合した短い語句・発言、公開名言集から話数を照合した名言要旨、セリフ・判断・言動の要旨、詳細出来事、検索用キーワードを分けて登録しています。横断照合は本編271話の候補URL521件を収集し、225話で2系統以上の記事を確保、128話で同一の正規化文言を確認できた972件だけを採用しました。アニメ・予想・考察・感想は除外し、二次記事だけで誤帰属しないよう話者名は原作ページ直接監査まで表示しません。

短文照合がない話も空欄にはせず、全275話へ既存の詳細あらすじから事実ベースの発言・判断・言動要旨を3～7件ずつ収録しています。第2話の「僕 最強だから」と第89話の「0.2秒の領域展開」も維持しています。

## 閲覧構造

PC版はデータベース向けの「左一覧＋右詳細」構造です。ページ全体へ情報カードを縦積みせず、右側を `概要 / 関連 / 出典・確認` などのタブで切り替えます。

- 一覧行：原則43px
- 一覧は左ペイン内だけをスクロール
- 詳細は見出しと要約を固定し、選択中タブの本文だけを表示
- 名言タブは、照合済み短文を最初の6件だけ3列表示し、残りを折りたたむ
- 名言要旨・言動要旨・キーワードを3列、詳細出来事を最大3列で表示
- コミックス収録話は短い表
- 上下キーで一覧移動、左右キーでタブ移動
- 820px以下では縦並びへ切替

右下の `文字サイズ` から、上部メニュー、左一覧、詳細タイトル、あらすじ、タブ、本文、項目、表など10項目を個別調整できます。変更値はブラウザへ保存され、`採用値をコピー` で最終固定用CSSを取得できます。この調整欄は採用値決定までの一時機能です。

公式コミックス表紙、人気投票画像、各話サムネイルは前版と同じ自然比率・最大320×408pxで表示します。

詳細は `docs/UI_STRUCTURE_V8.md` を参照してください。

## 開き方

最上位の `index.html` をChromeで開くと、各話ページへ移動します。`chapters.html` を直接開いても構いません。`file://` のスクリプト読込をブラウザ設定が遮断する場合は、フォルダ内で次を実行します。

```powershell
python tools/serve.py
```

表示された `http://127.0.0.1:8000/chapters.html` を開きます。

## 公式画像の扱い

画像ファイルはZIPへ複製せず、集英社・少年ジャンプ公式ページの外部URLだけを保持します。ブラウザは一覧画像を一括読込せず、選択中の1件だけを読み込みます。

原本台帳：

```text
data/source/media_registry.json
```

各話サムネイル台帳を公式ページから更新する場合：

```powershell
python tools/refresh_official_images.py
```

取得前に挙動だけ確認する場合：

```powershell
python tools/refresh_official_images.py --dry-run --limit 4
```

このスクリプトは画像ファイルを保存せず、公式エピソードURLと公式画像URLだけを台帳へ書き込みます。別作品へ遷移した場合、許可外ドメインを検出した場合、話数を確定できない場合は停止します。

## 編集・生成・検査

1. `data/source` の原本データを修正する
2. 必要な場合だけ `JUJUTSU_CACHE_ONLY=1 python tools/research_manga_facts.py`
3. `python tools/build_chapter_highlights.py`
4. `python tools/build_site.py`
5. `python tools/validate_site.py`
6. `python tools/audit_volumes.py`
7. `python tools/audit_data_quality.py`
8. `python tools/audit_official_media.py`
9. `python tools/test_official_image_parser.py`
10. `node tools/test_core_media.js`
11. HTMLを開いて確認する
12. `python tools/make_manifest.py`

`data/generated` は表示用生成物です。直接編集しません。

`research_manga_facts.py` は取得済みキャッシュを再解析できます。ネットワーク再収集時の失敗URLは `reports/MANGA_SOURCE_RESEARCH.json` に残し、取得できなかった話を推測で補完しません。
